§GuiParams

The OdenPlugin::gui function is called each frame if the sidebar GUI of the plugin entity is visible.

GuiParams is a struct that exposes the Oden Plugin API functions associated with the OdenPlugin::gui function. The API is passed as a parameter to gui(&mut self, api: &GuiParams) and the API can be accessed as shown in the example below:

§Examples

ⓘ
fn gui(&mut self, api: &GuiParams) {
    api.label("Hello World!");
}
