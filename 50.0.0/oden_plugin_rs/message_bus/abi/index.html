oden_plugin_rs::message_bus

Module abi 

Source
Expand description

ABI for the cross-plugin message bus.

Everything in this module is #[repr(C)] and crosses the plugin boundary. It must stay stable so plugins built with different toolchains can interoperate. See the message_bus module-level documentation for the design rationale and buffer-ownership rules.

Structs§

BusBytes
Borrowed view of opaque bytes. Input-only; the callee copies before returning.
BusHandle
The thin client-side handle. Pairs a vtable pointer with the owner-allocated this.
BusHostVTable
vtable behind the bus factory record published by the host (see the host module). Its function pointers live in the host executable, which is never unloaded, so a bus allocated through it survives any plugin DLL unload.
BusStatus
Status code returned by every vtable function. A #[repr(transparent)] wrapper over u32 rather than a Rust enum so that a code minted by a build with newer status values is an ordinary value to receive — not an invalid enum discriminant, which would be UB at the call site. Callers must treat unknown codes as errors.
BusStr
Borrowed view of a UTF-8 string. Input-only; the callee copies before returning.
BusVTable
vtable for a live bus. Buses are only allocated through BusHostVTable, so these function pointers run in the host executable and its allocator owns every internal allocation.
