1//! Generic 1↔N message bus shared between plugins.
2//!
3//! # Design
4//!
5//! One *owner* plugin creates a `BusOwner` under a well-known UUID. Any other
6//! plugin in the same process opens a `BusClient` against that UUID. Clients can
7//! `subscribe` to named messages broadcast by the owner (downstream) and `send`
8//! messages back to the owner (upstream).
9//!
10//! # ABI stability across toolchains and allocators
11//!
12//! The shared state lives behind a vtable published alongside it. Every function
13//! pointer in that vtable runs in the host executable's translation unit, so one `std`
14//! and global allocator own the bus's internal `HashMap`, `Mutex`, `mpsc` channels, and
15//! queued message `Vec<u8>`s. Plugins only touch `#[repr(C)]` POD across the boundary:
16//! borrowed `BusStr`/`BusBytes` (input) and caller-allocated output buffers. No
17//! `Vec`/`String`/`Arc` ever flows between sides, so a client built with a different
18//! Rust toolchain or `#[global_allocator]` than the owner is fine — there is no
19//! cross-boundary `free`.
20//!
21//! # Receive contract
22//!
23//! The ABI's receive functions take caller-allocated output buffers. If the buffers are
24//! too small, the bus writes the required sizes and returns `BufferTooSmall` *without
25//! popping the message*; the same message is delivered on retry once buffers are big
26//! enough. The safe Rust facade in this module hides that retry loop, so users only
27//! see `Option<OwnedMessage>`.
28//!
29//! # Late subscribers
30//!
31//! A broadcast that matches no live subscription is parked inside the bus (up to 128
32//! messages) and handed, in order, to the first later subscription whose name filter
33//! matches. Parked messages that don't fit in the claiming subscription's queue are
34//! dropped — impossible with the default queue capacity (128, matching the parked
35//! buffer), possible with a smaller explicit capacity. This mirrors the old
36//! named-channel behavior where messages sent before
37//! the consumer attached waited in the queue, and covers the window between a
38//! webview page connecting and a client plugin's first subscribe (startup, project
39//! load, bus reconnect). A message that matched at least one subscription at
40//! broadcast time is never re-delivered to subscriptions created later.
41//!
42//! # Lifecycle: the bus outlives owners and clients
43//!
44//! The bus under a UUID is a process-lifetime mailbox living in the host
45//! executable. The first endpoint to dial a UUID — owner or client — allocates it
46//! through the host's factory record (see [`host`]) and publishes its address in
47//! the discovery record; every later [`BusOwner::open`] or [`BusClient::open`]
48//! for the same UUID adopts that same bus. It is never torn down: subscriptions,
49//! queued messages, and pending receive futures all stay valid while the owner
50//! plugin is unloaded, hot-reloaded, or restarted. Clients subscribe once and
51//! simply see no messages while no owner is broadcasting; upstream sends wait in
52//! the bounded upstream queue for the next owner to drain them. There is no
53//! liveness state to poll.
54//!
55//! The `BusState` allocation is **never freed**. Its address is embedded in the
56//! discovery record published through `SettingsApi`, which exposes no way to retract a
57//! record, so freeing would leave a dangling pointer for a later `open` to
58//! dereference. It is leaked for the process lifetime — one allocation per UUID —
59//! mirroring `named_shared_data`'s leaked holder.
60//!
61//! Because the bus vtable and `BusState` live in the host executable, they survive
62//! any plugin DLL/SO unload. A host that publishes no factory record cannot run
63//! buses — `open` panics rather than allocating the bus inside the
64//! plugin's own DLL, where an unload would unmap it under live users. That unload
65//! hazard still exists for `named_mpmc_channel` and `named_shared_data`, whose
66//! state lives in the owning plugin.
67//!
68//! One hazard remains for the bus: wake callbacks registered by
69//! [`Subscription::recv_async`] / [`BusOwner::recv_upstream_async`] point into the
70//! plugin that polled the future. Dropping the future unregisters them, so this only
71//! bites a plugin that leaks a pending `RecvFuture` past its own unload.
72

91/// A message delivered from / received by the bus, owned by the caller's allocator.
92#[derive(Debug, Clone, PartialEq, Eq)]
93pub struct OwnedMessage {
94    /// Routing name. UTF-8.
95    pub name: String,
96    /// Opaque payload bytes (often JSON, but the bus does not interpret them).
97    pub payload: Vec<u8>,
98}

100/// Error returned by [`BusOwner::broadcast`] and [`BusClient::send`].
101#[derive(Debug, Clone, Copy, PartialEq, Eq)]
102pub enum SendError {
103    /// A bounded queue was full. For `send` this means the upstream queue. For
104    /// `broadcast` it means at least one subscriber's queue was full — the
105    /// broadcast still delivered to subscribers whose queues had space.
106    QueueFull,
107}

133// ---------------------------------------------------------------------------
134// Discovery — how the first endpoint publishes the bus and later ones adopt it.
135// ---------------------------------------------------------------------------
136
137/// Magic prefix on every bus discovery record. Bump this if the layout of the
138/// `BusVTable` or the discovery record ever needs an incompatible change post-merge.
139const DISCOVERY_MAGIC: [u8; 8] = *b"ODENBUSD";
140
141/// Size in bytes of the on-wire discovery record. 8 (magic) + 1 (pointer width) +
142/// 7 (reserved) + 8 (vtable) + 8 (this) = 32.
143const DISCOVERY_RECORD_SIZE: usize = 32;
144
145fn discovery_key(owner_uuid: &Uuid) -> String {
146    format!("oden_message_bus.{owner_uuid}")
147}
148
149/// Serialize a `BusHandle` into a discovery record byte string. Fixed layout, all
150/// integers little-endian, no padding.
151fn write_discovery_record(handle: BusHandle) -> [u8; DISCOVERY_RECORD_SIZE] {
152    let mut out = [0u8; DISCOVERY_RECORD_SIZE];
153    out[0..8].copy_from_slice(&DISCOVERY_MAGIC);
154    out[8] = std::mem::size_of::<usize>() as u8;
155    // out[9..16] reserved, left zero.
156    out[16..24].copy_from_slice(&(handle.vtable as usize as u64).to_le_bytes());
157    out[24..32].copy_from_slice(&(handle.this as usize as u64).to_le_bytes());
158    out
159}
160
161/// Parse a discovery record byte string. Returns `None` if the magic or pointer
162/// width don't match this build.
163fn read_discovery_record(bytes: &[u8]) -> Option<BusHandle> {
164    if bytes.len() != DISCOVERY_RECORD_SIZE {
165        return None;
166    }
167    if bytes[0..8] != DISCOVERY_MAGIC {
168        return None;
169    }
170    if bytes[8] as usize != std::mem::size_of::<usize>() {
171        return None;
172    }
173    let vtable_addr = u64::from_le_bytes(bytes[16..24].try_into().ok()?);
174    let this_addr = u64::from_le_bytes(bytes[24..32].try_into().ok()?);
175    if vtable_addr == 0 || this_addr == 0 {
176        return None;
177    }
178    Some(BusHandle {
179        vtable: vtable_addr as usize as *const abi::BusVTable,
180        this: this_addr as usize as *mut c_void,
181    })
182}

184/// Adopt the bus published under `owner_uuid`, or allocate it through the host's
185/// factory and publish it if none exists yet (or only a corrupt record does).
186/// Returns an owned reference either way.
187///
188/// # Panics
189///
190/// If the bus has to be created and the host publishes no valid factory record.
191fn open_or_create_bus(api: &dyn SettingsApi, owner_uuid: &Uuid) -> BusHandle {
192    let key = discovery_key(owner_uuid);
193
194    if let Ok((data, _)) = api.query_data(&key, DISCOVERY_RECORD_SIZE as i32) {
195        if let Some(handle) = read_discovery_record(&data) {
196            // SAFETY: `read_discovery_record` only rejects corrupt or mismatched
197            // records; it cannot prove the pointers are live. That rests on the
198            // trust model: this key is only ever written by plugins in this
199            // process running this function, and the `BusState` a record points
200            // at is never freed (see `imp::release`).
201            unsafe { ((*handle.vtable).retain)(handle.this) };
202            return handle;
203        }
204    }
205
206    // The handle returned by the factory starts with refcount 1, which becomes
207    // this caller's reference.
208    let handle = host::create_bus_via_host(api)
209        .expect("host did not publish a valid message bus factory record");
210    api.publish_data(&key, &write_discovery_record(handle));
211    handle
212}

218/// Owner-side handle. Created by the plugin that wants to be addressable.
219///
220/// Cloning is cheap. Dropping every owner leaves the bus fully intact —
221/// subscriptions keep their queued messages, clients keep sending into the
222/// bounded upstream queue, and the next `open` under the same UUID picks up
223/// right where the previous owner left off.
224#[derive(Clone)]
225pub struct BusOwner {
226    inner: Arc<BusInner>,
227}
228
229impl BusOwner {
230    /// Adopt (or create, if no endpoint has dialed it yet) the bus published
231    /// under `owner_uuid` — the well-known address clients pass to
232    /// [`BusClient::open`]. Use [`Uuid::parse`] in a `const` so a malformed
233    /// literal fails at compile time. The plugin's host-assigned
234    /// entity/instance UUID is deliberately not used here: for global plugin
235    /// entities the host generates a random per-installation entity UUID, so a
236    /// key derived from it would never match the constant clients dial.
237    ///
238    /// The bus is allocated inside the host executable through its factory
239    /// record (see [`host`]), so it stays valid even if this plugin's library
240    /// is unloaded.
241    ///
242    /// # Panics
243    ///
244    /// If the host publishes no valid bus factory record.
245    pub fn open(api: &dyn SettingsApi, owner_uuid: Uuid) -> Self {
246        Self {
247            inner: BusInner::new(open_or_create_bus(api, &owner_uuid)),
248        }
249    }
250
251    /// Broadcast a message to every subscriber whose subscription includes `name`.
252    /// If no subscription matches, the message is parked for the first later
253    /// subscription that wants it (see the module docs on late subscribers).
254    ///
255    /// Returns `Err(QueueFull)` if at least one subscriber's queue was full — the
256    /// broadcast still delivered to subscribers whose queues had space — or if the
257    /// message matched no subscription and the parked buffer was full.
258    pub fn broadcast(&self, name: &str, payload: &[u8]) -> Result<(), SendError> {
259        let h = self.inner.handle;
260        let n = BusStr {
261            ptr: name.as_ptr(),
262            len: name.len(),
263        };
264        let p = BusBytes {
265            ptr: payload.as_ptr(),
266            len: payload.len(),
267        };
268        match unsafe { ((*h.vtable).try_broadcast)(h.this, n, p) } {
269            BusStatus::OK => Ok(()),
270            _ => Err(SendError::QueueFull),
271        }
272    }
273
274    /// Drain the upstream lane (messages sent by clients) without waiting for a
275    /// message. Blocks while a concurrent `recv_upstream_timeout` on any clone
276    /// of this owner is waiting.
277    pub fn try_recv_upstream(&self) -> Option<OwnedMessage> {
278        let h = self.inner.handle;
279        recv_via(
280            |name_buf, name_cap, name_len, pl_buf, pl_cap, pl_len| unsafe {
281                ((*h.vtable).try_recv_upstream)(
282                    h.this, name_buf, name_cap, name_len, pl_buf, pl_cap, pl_len,
283                )
284            },
285        )
286        .ok()
287    }
288
289    /// Blocking drain of the upstream lane. Returns `None` if no message arrived
290    /// within `timeout`.
291    pub fn recv_upstream_timeout(&self, timeout: Duration) -> Option<OwnedMessage> {
292        let h = self.inner.handle;
293        let ns = duration_to_ns(timeout);
294        recv_via(
295            |name_buf, name_cap, name_len, pl_buf, pl_cap, pl_len| unsafe {
296                ((*h.vtable).recv_upstream_timeout)(
297                    h.this, ns, name_buf, name_cap, name_len, pl_buf, pl_cap, pl_len,
298                )
299            },
300        )
301        .ok()
302    }
303
304    /// Async drain of the upstream lane. Resolves when a message arrives.
305    /// Runtime-agnostic: works with any executor that respects `Waker`.
306    pub fn recv_upstream_async(&self) -> RecvFuture {
307        RecvFuture::new(self.inner.clone(), 0)
308    }
309}

315/// Client-side handle for a bus owned by some other plugin.
316///
317/// Cloning is cheap. The client needs no liveness handling: it stays valid
318/// across owner unloads and restarts (see the module docs on lifecycle).
319#[derive(Clone)]
320pub struct BusClient {
321    inner: Arc<BusInner>,
322}
323
324impl BusClient {
325    /// Open the bus published under `owner_uuid`, creating it if no endpoint has
326    /// dialed that UUID yet — subscriptions made before the owner plugin starts
327    /// receive its broadcasts once it does.
328    ///
329    /// # Panics
330    ///
331    /// If the bus has to be created and the host publishes no valid bus factory
332    /// record.
333    pub fn open(api: &dyn SettingsApi, owner_uuid: Uuid) -> Self {
334        Self {
335            inner: BusInner::new(open_or_create_bus(api, &owner_uuid)),
336        }
337    }
338
339    /// Subscribe to one or more named messages. The returned `Subscription` drops
340    /// the subscription on drop.
341    pub fn subscribe(&self, names: &[&str]) -> Subscription {
342        self.subscribe_with_capacity(names, 0)
343    }
344
345    /// Subscribe with an explicit queue capacity. `capacity == 0` uses the default (128).
346    pub fn subscribe_with_capacity(&self, names: &[&str], capacity: usize) -> Subscription {
347        let h = self.inner.handle;
348        let bus_strs: Vec<BusStr> = names
349            .iter()
350            .map(|n| BusStr {
351                ptr: n.as_ptr(),
352                len: n.len(),
353            })
354            .collect();
355        let mut handle: BusSubHandle = 0;
356        let status = unsafe {
357            ((*h.vtable).subscribe)(
358                h.this,
359                bus_strs.as_ptr(),
360                bus_strs.len(),
361                capacity,
362                &mut handle as *mut BusSubHandle,
363            )
364        };
365        assert!(status == BusStatus::OK, "bus subscribe failed: {status:?}");
366        Subscription {
367            bus: self.inner.clone(),
368            handle,
369        }
370    }
371
372    /// Send a message to the bus owner. Messages sent while no owner is draining
373    /// wait in the bounded upstream queue for the next owner.
374    ///
375    /// Returns `Err(QueueFull)` if the upstream queue is full.
376    pub fn send(&self, name: &str, payload: &[u8]) -> Result<(), SendError> {
377        let h = self.inner.handle;
378        let n = BusStr {
379            ptr: name.as_ptr(),
380            len: name.len(),
381        };
382        let p = BusBytes {
383            ptr: payload.as_ptr(),
384            len: payload.len(),
385        };
386        match unsafe { ((*h.vtable).send_upstream)(h.this, n, p) } {
387            BusStatus::OK => Ok(()),
388            _ => Err(SendError::QueueFull),
389        }
390    }
391}

397/// A live subscription. Drops the subscription on `Drop`.
398pub struct Subscription {
399    bus: Arc<BusInner>,
400    handle: BusSubHandle,
401}
402
403impl Subscription {
404    /// Receive without waiting for a message. Returns `None` if no message is
405    /// queued. Blocks while a concurrent `recv_timeout` on this subscription is
406    /// waiting.
407    pub fn try_recv(&self) -> Option<OwnedMessage> {
408        let h = self.bus.handle;
409        let sub = self.handle;
410        recv_via(
411            |name_buf, name_cap, name_len, pl_buf, pl_cap, pl_len| unsafe {
412                ((*h.vtable).try_recv_downstream)(
413                    h.this, sub, name_buf, name_cap, name_len, pl_buf, pl_cap, pl_len,
414                )
415            },
416        )
417        .ok()
418    }
419
420    /// Blocking receive. Returns `None` if no message arrived within `timeout`.
421    pub fn recv_timeout(&self, timeout: Duration) -> Option<OwnedMessage> {
422        let h = self.bus.handle;
423        let sub = self.handle;
424        let ns = duration_to_ns(timeout);
425        recv_via(
426            |name_buf, name_cap, name_len, pl_buf, pl_cap, pl_len| unsafe {
427                ((*h.vtable).recv_downstream_timeout)(
428                    h.this, sub, ns, name_buf, name_cap, name_len, pl_buf, pl_cap, pl_len,
429                )
430            },
431        )
432        .ok()
433    }
434
435    /// Async receive. Resolves when a message arrives.
436    /// Runtime-agnostic: works with any executor that respects `Waker`.
437    ///
438    /// The future is cancel-safe: dropping it before resolution unregisters the
439    /// wake callback and leaves any queued message in the queue for the next
440    /// receiver.
441    pub fn recv_async(&self) -> RecvFuture {
442        RecvFuture::new(self.bus.clone(), self.handle)
443    }
444}
445
446impl Drop for Subscription {
447    fn drop(&mut self) {
448        let h = self.bus.handle;
449        unsafe { ((*h.vtable).unsubscribe)(h.this, self.handle) };
450    }
451}

457fn duration_to_ns(d: Duration) -> u64 {
458    u64::try_from(d.as_nanos()).unwrap_or(u64::MAX)
459}

461/// Why a receive produced no message.
462#[derive(Debug, Clone, Copy, PartialEq, Eq)]
463enum RecvFail {
464    /// Nothing queued (or the wait timed out). Receiving later can succeed.
465    Empty,
466    /// The lane can never produce a message again (the subscription was
467    /// dropped, or the bus returned an unknown status code).
468    Dead,
469}
470
471/// Hide the `BufferTooSmall` retry loop. Starts with reasonable scratch capacities and
472/// grows them on demand. `call` invokes the underlying ABI recv with our buffers.
473fn recv_via<F>(mut call: F) -> Result<OwnedMessage, RecvFail>
474where
475    F: FnMut(*mut u8, usize, *mut usize, *mut u8, usize, *mut usize) -> BusStatus,
476{
477    let mut name = Vec::<u8>::with_capacity(64);
478    let mut payload = Vec::<u8>::with_capacity(256);
479
480    loop {
481        let mut name_len: usize = 0;
482        let mut payload_len: usize = 0;
483        let status = call(
484            name.as_mut_ptr(),
485            name.capacity(),
486            &mut name_len as *mut usize,
487            payload.as_mut_ptr(),
488            payload.capacity(),
489            &mut payload_len as *mut usize,
490        );
491        match status {
492            BusStatus::OK => {
493                unsafe {
494                    name.set_len(name_len);
495                    payload.set_len(payload_len);
496                }
497                let name_str = String::from_utf8(name)
498                    .unwrap_or_else(|e| String::from_utf8_lossy(e.as_bytes()).into_owned());
499                return Ok(OwnedMessage {
500                    name: name_str,
501                    payload,
502                });
503            }
504            BusStatus::EMPTY => return Err(RecvFail::Empty),
505            BusStatus::BUFFER_TOO_SMALL => {
506                // len is 0 here, so `reserve_exact(n)` guarantees capacity >= n.
507                if name.capacity() < name_len {
508                    name.reserve_exact(name_len);
509                }
510                if payload.capacity() < payload_len {
511                    payload.reserve_exact(payload_len);
512                }
513            }
514            // INVALID_HANDLE, QUEUE_FULL (never returned by recvs), and any code
515            // minted by a newer build. An unknown code must never reach the
516            // retry arm above — retrying on unknown semantics could loop
517            // forever.
518            _ => return Err(RecvFail::Dead),
519        }
520    }
521}

527/// Shared state between the future and the C wake callback. Held via `Arc`; the
528/// bus owns one reference per live one-shot registration, released by exactly
529/// one of `wake_trampoline` (fire) or `drop_ctx_trampoline` (unregister).
530struct RecvWaker {
531    state: Mutex<RecvWakerState>,
532}
533
534struct RecvWakerState {
535    waker: Option<Waker>,
536    /// Set by `wake_trampoline`. Tells the next `poll` that its registration
537    /// was consumed and it must re-register before peeking again.
538    fired: bool,
539}
540
541impl RecvWaker {
542    fn new() -> Arc<Self> {
543        Arc::new(Self {
544            state: Mutex::new(RecvWakerState {
545                waker: None,
546                fired: false,
547            }),
548        })
549    }
550}
551
552/// Drop one `RecvWaker` reference.
553unsafe extern "C" fn drop_ctx_trampoline(ctx: *mut c_void) {
554    drop(unsafe { Arc::from_raw(ctx as *const RecvWaker) });
555}
556
557/// Consume the registration's reference: mark it fired, take the stored
558/// `Waker`, then wake outside the lock.
559unsafe extern "C" fn wake_trampoline(ctx: *mut c_void) {
560    let state = unsafe { Arc::from_raw(ctx as *const RecvWaker) };
561    let waker_to_wake = match state.state.lock() {
562        Ok(mut s) => {
563            s.fired = true;
564            s.waker.take()
565        }
566        Err(_) => None,
567    };
568    if let Some(w) = waker_to_wake {
569        w.wake();
570    }
571}

573/// Future returned by [`BusOwner::recv_upstream_async`] and [`Subscription::recv_async`].
574///
575/// Resolves with `Some(message)` when a message arrives, or `None` if the lane
576/// can never produce one again (the subscription was dropped while the future
577/// was pending).
578///
579/// Cancel-safe: dropping it before resolution removes its wake registration and
580/// leaves any queued message in the queue for the next receiver. Multiple
581/// concurrent futures on the same lane each hold their own registration; a
582/// message wakes them all and the first to poll takes it.
583pub struct RecvFuture {
584    bus: Arc<BusInner>,
585    /// `0` means the upstream lane on the owner side; non-zero is a client
586    /// subscription handle.
587    sub: BusSubHandle,
588    state: Arc<RecvWaker>,
589    /// Token of the live one-shot registration, if any. A fire consumes the
590    /// registration (`fired` flips true), so `poll` re-registers before
591    /// peeking again.
592    token: Option<u64>,
593}
594
595impl RecvFuture {
596    fn new(bus: Arc<BusInner>, sub: BusSubHandle) -> Self {
597        Self {
598            bus,
599            sub,
600            state: RecvWaker::new(),
601            token: None,
602        }
603    }
604
605    fn try_recv_once(&self) -> Result<OwnedMessage, RecvFail> {
606        let h = self.bus.handle;
607        let sub = self.sub;
608        recv_via(
609            |name_buf, name_cap, name_len, pl_buf, pl_cap, pl_len| unsafe {
610                if sub == 0 {
611                    ((*h.vtable).try_recv_upstream)(
612                        h.this, name_buf, name_cap, name_len, pl_buf, pl_cap, pl_len,
613                    )
614                } else {
615                    ((*h.vtable).try_recv_downstream)(
616                        h.this, sub, name_buf, name_cap, name_len, pl_buf, pl_cap, pl_len,
617                    )
618                }
619            },
620        )
621    }
622}
623
624impl Future for RecvFuture {
625    type Output = Option<OwnedMessage>;
626
627    fn poll(mut self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<Self::Output> {
628        let needs_register = {
629            let mut state = match self.state.state.lock() {
630                Ok(g) => g,
631                Err(_) => return Poll::Ready(None),
632            };
633            state.waker = Some(cx.waker().clone());
634            let fired = state.fired;
635            state.fired = false;
636            fired || self.token.is_none()
637        };
638
639        if needs_register {
640            self.token = None;
641            // Hand the bus one freshly-incremented reference for it to own. On
642            // any non-Ok status the bus has not taken ownership and we reclaim
643            // the reference ourselves.
644            let ctx = Arc::into_raw(self.state.clone()) as *mut c_void;
645            let h = self.bus.handle;
646            let mut token: u64 = 0;
647            let status = unsafe {
648                ((*h.vtable).register_waker)(
649                    h.this,
650                    self.sub,
651                    wake_trampoline,
652                    drop_ctx_trampoline,
653                    ctx,
654                    &mut token as *mut u64,
655                )
656            };
657            if status == BusStatus::OK {
658                self.token = Some(token);
659            } else {
660                drop(unsafe { Arc::from_raw(ctx as *const RecvWaker) });
661                // The subscription vanished. Drain anything still queued before
662                // reporting the dead lane — no further wake will ever come, so
663                // never return Pending from here.
664                return Poll::Ready(self.try_recv_once().ok());
665            }
666        }
667
668        // Race-safe peek: with the registration live, any message that arrives
669        // after this point will fire `wake_trampoline`. Anything already in the
670        // queue is delivered here.
671        match self.try_recv_once() {
672            Ok(msg) => Poll::Ready(Some(msg)),
673            Err(RecvFail::Empty) => Poll::Pending,
674            Err(RecvFail::Dead) => Poll::Ready(None),
675        }
676    }
677}
678
679impl Drop for RecvFuture {
680    fn drop(&mut self) {
681        // Release the bus-held reference if our registration is still live. If
682        // it already fired, the token is gone and this is a no-op — the
683        // reference was consumed by the wake.
684        if let Some(token) = self.token {
685            let h = self.bus.handle;
686            unsafe {
687                ((*h.vtable).unregister_waker)(h.this, self.sub, token);
688            }
689        }
690    }
691}
